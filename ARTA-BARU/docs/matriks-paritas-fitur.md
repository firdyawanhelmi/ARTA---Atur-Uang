## Utang teknis legacy (jangan disalin)

- `.no-scroll` tak konsisten (kunci/lepas scroll saat modal+drawer+picker+tumpuk);
  PRD P54 menuntut preservasi posisi scroll + larang bug `.no-scroll` global.
- LWW + `uid()=Date.now()+random` + `updatedAt=Date.now()` sebagai otoritas —
  dilarang; baru: `operation_id` + `expected_version` + 409 + idempoten.
- Hapus permanen tanpa Trash/undo; `version mismatch` (1.3.2/1.3.3/1.3.5/SW v36);
  `theme-color` beda manifest vs index; `dist/` kosong; CDN tanpa SRI gagal
  offline; `innerHTML` masif + log `[SYNC]*` bising; toast monokrom sulit beda
  status; O(n) scan sheet; lock per-modal; `localStorage` ~5MB untuk foto.
